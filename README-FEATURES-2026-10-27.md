# AAT Journal – Feature Update

## Latest changes

### Certificates moved to the sidebar
Certificates are now a dedicated top-level page in the sidebar, alongside Home, Journal, Accounts, Rules, and Calendar. The Accounts page no longer contains the certificate upload/gallery section.

The Certificates page still supports:
- Funded Certificate
- Payout Certificate
- Other
- Image or PDF uploads
- Optional account linking
- Open/delete actions

### Random Trade Share quotes
Every newly opened Trade Share card now chooses a quote at random from a larger quote library. The quote stays fixed while that share card is open, so changing the background does not unexpectedly change the quote.

## Run

From `frontend`:

```powershell
npm install
npm run build
npm run dev
```

The ZIP intentionally does not include `node_modules`.
